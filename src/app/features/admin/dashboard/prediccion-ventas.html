¿Cómo se calculan las proyecciones y la reposición?

Stock proyectado = stock actual − demanda semanal redondeada hacia arriba. Un número negativo significa faltante, no stock físico negativo. Reposición sugerida = el mayor valor entre el déficit real de variantes y la demanda redondeada + suma de mínimos − stock actual (nunca menor a cero). Sin escenario ML solo se considera el déficit real por variante. La demanda no se distribuye por talla o color y las recomendaciones no generan compras automáticas.
